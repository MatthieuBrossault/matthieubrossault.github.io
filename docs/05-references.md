# References & inspiration

## Hostinger: Web developer portfolio guide

**Source:** [24 web developer portfolio examples](https://www.hostinger.com/tutorials/web-developer-portfolio) — tips and sample portfolios.

### Tips from the article

- **Contact form** — place it prominently to get more clients.
- **Social proof** — testimonials from clients to build trust.
- **Engaging design** — increases credibility and brand recognition.
- **Curate projects** — show only your best work; if entry-level, include open-source contributions.
- **List skills & credentials** — programming skills, experience, education, certifications.
- **Domain name** — professional and memorable (.com, .me, .dev, .tech).
- **Reliable hosting** — so the portfolio is fast and always available.
