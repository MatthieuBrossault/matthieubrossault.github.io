# Overview

## Goal

This solution provides a **portfolio website** for a web developer — web engineer / web architect.

It serves to:

- **Support recruitment and job search** — primary channel for future employers and opportunities.
- **Sell the developer** — present the profile in a compelling way and demonstrate capability.
- **Act as a CV** — the site is the resume: skills, experience, and projects in one place.

## Audience & locale

- **Market** — recruitment is primarily in **France** (developer works exclusively there).
- **Languages** — **English and French**. Both to showcase language skills and to serve French recruiters and international readers. Default language follows **browser preference** (e.g. `Accept-Language`) or **location** when detectable; optional manual switcher to override.

## Constraints

- **Single developer** — no team; one person builds and maintains everything.
- **Minimal effort and cost** — low development/maintenance time and low or zero hosting/deployment cost. Prefer simple, static, free-tier-friendly options.
